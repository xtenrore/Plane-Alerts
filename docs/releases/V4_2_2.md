# Plane Alerts v4.2.2

v4.2.2 is an retired external agent and Prediction Lab resilience update.

## Changes

- Detect headless permission denials even when the retired external agent CLI reports a successful process exit.
- Retry denied goal cycles with bounded backoff instead of waiting for the normal hourly cycle.
- Keep strict command permissions; no global or broad shell bypass is enabled.
- Require multi-line audit scripts to be written with `write_to_file` and executed separately with allowlisted `python3`.
- Force one immediate goal cycle when the tooling policy version changes.
- Run long Next60 and Europe-sentinel shadow scans on one bounded background worker so redacted context refresh and handoff publishing remain responsive.
- Continue deploying the exact CI-tested Git SHA to both Railway services.

## Safety boundary

This release does not change live trajectory, CPA, ETA, pass/no-pass, qualification, cancellation, or alert timing logic. Paid AI/API overages remain disabled for retired external agent.
