# Plane Alerts v5.7.1 — Bug Fixes Update

Plane Alerts v5.7.1 is the cumulative bug-fix release that promotes the verified v5.6.x storage and reliability recovery into the next release line. It intentionally introduces no new aircraft-prediction behavior.

## Included fixes

- MongoDB remains authoritative for durable user/account state, Telegram identity, locations, profiles, preferences/settings and application configuration.
- High-volume operational route history, notification lifecycle telemetry and Prediction Lab evidence remain outside MongoDB on bounded persistent-volume storage.
- Legacy operational Mongo writers/exporters were retired and retirement was made idempotent so retired collections are not recreated or repeatedly touched.
- Route history and notification telemetry use bounded volume-backed SQLite/file storage without entering the alert-critical five-second path.
- Persistent-volume recovery protects unsynced evidence and operational SQLite databases while safely removing only proven disposable or repository-acknowledged data.
- Prediction Lab applies low-space backpressure and lossless compaction so optional analytical evidence cannot starve operational storage.
- Repository synchronization uses the authenticated HTTP bridge. GitHub independently validates path, byte count, SHA-256, schema and credential-safety before committing exact evidence bytes to `prediction-lab-data`.
- Runtime evidence is removed only after the Git push succeeds and the exact path + size + SHA-256 acknowledgement is returned.
- Malformed, legacy, sensitive or oversized raw objects remain preserved and are skipped instead of blocking valid evidence behind them or being deleted blindly.
- Production recovery demonstrated recovery from a zero-free-byte persistent volume to roughly 192 MiB of usable headroom, after which disk-full, route-history-write and notification-background-write failures stopped.
- The five-second monitoring cadence remained healthy through the storage recovery.

## Prediction contract

No trajectory, CPA, ETA, confidence, destination/path qualification, pass/no-pass, cancellation or alert-timing behavior changes are introduced by v5.7.1.

Physical prediction version: `5.3-3d-proximity-age-aware`.

## Release boundary

The detailed v5.6.x patch notes remain in the repository as engineering history. v5.7.1 is the cumulative public **Bug Fixes Update** identity for those verified fixes and creates a clean release boundary for subsequent Plane Alerts 5.x work on the road to 6.0.

This release branch is prepared on GitHub independently of production deployment. Railway should only move to the v5.7.1 identity after the exact release commit passes CI and is deliberately deployed, because Prediction Lab synchronization requires the running bridge version to match the workflow release identity exactly.
