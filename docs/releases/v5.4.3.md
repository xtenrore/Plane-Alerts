# Plane Alerts v5.4.3 — retired external agent Removal

Plane Alerts v5.4.3 permanently removes the retired retired external agent/retired external agent sidecar integration from the active project and production runtime.

## Removed

- The dedicated retired external agent Railway service and its persistent state volume.
- The `/retired_agent` Telegram command, handler registration and bot command-menu entry.
- retired external agent worker, console, state, permission/recovery and prediction-bridge modules.
- retired external agent Dockerfile, dependency file and worker/bridge helper scripts.
- retired external agent-specific environment settings and example variables.
- retired external agent-only test suites and CI stages.
- The standalone quota snapshot file used for the retired integration.

The v5.3 provider-age and stale-cancellation regressions remain because they protect production prediction behavior; their test filename and documentation are renamed to remove the retired integration name.

## Safety

This release does not change trajectory, CPA, ETA, confidence, terminal inference, qualification, cancellation thresholds, provider polling or alert timing. The physical prediction version remains `5.3-3d-proximity-age-aware`.

Normal Plane Alerts runtime contains no code path that can start, authenticate, call or restart the retired retired external agent/retired external agent integration.
