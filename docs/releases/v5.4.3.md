# Plane Alerts v5.4.3 — AGY Removal

Plane Alerts v5.4.3 permanently removes the retired AGY/Antigravity sidecar integration from the active project and production runtime.

## Removed

- The dedicated AGY Railway service and its persistent state volume.
- The `/agy` Telegram command, handler registration and bot command-menu entry.
- AGY worker, console, state, permission/recovery and prediction-bridge modules.
- AGY Dockerfile, dependency file and worker/bridge helper scripts.
- AGY-specific environment settings and example variables.
- AGY-only test suites and CI stages.
- The standalone quota snapshot file used for the retired integration.

The v5.3 provider-age and stale-cancellation regressions remain because they protect production prediction behavior; their test filename and documentation are renamed to remove the retired integration name.

## Safety

This release does not change trajectory, CPA, ETA, confidence, terminal inference, qualification, cancellation thresholds, provider polling or alert timing. The physical prediction version remains `5.3-3d-proximity-age-aware`.

Normal Plane Alerts runtime contains no code path that can start, authenticate, call or restart the retired AGY/Antigravity integration.
