# Plane Alerts v4.7.1

## Worldwide airport/runway reference data

Plane Alerts v4.7.1 completes the v4.7 airport-intelligence data layer with a worldwide local airport/runway catalogue.

### Changes

- Added a commit-pinned OurAirports snapshot as the global reference source.
- Compiles the snapshot into `data/aviation/compiled/global_airports.sqlite3` during the production image build.
- Runtime airport/runway lookups are local, read-only SQLite operations; no OurAirports API key or runtime network call is required.
- Added spatial-cell indexing and bounded lookup caches so the global catalogue is not loaded into memory or scanned in the five-second monitoring path.
- Preserves airports without ICAO codes and closed facilities in the reference database while excluding closed facilities from normal nearby-airport inference.
- Preserves incomplete runway records but only exposes runway-relative geometry when both ends have usable coordinates/headings.
- Added an override layer for stronger maintained sources. LTFM/IST is overridden with the five verified operational runway pairs already used by Plane Alerts.
- Added global coverage validation and airport-lookup performance gates to CI.

### Prediction safety

This release does not introduce a competing predictor. It supplies worldwide airport/runway geometry to the existing v4.7 terminal model. Fresh ADS-B observations and live geometry remain authoritative. Runway/base/final/holding suppression hypotheses remain shadow-only; the existing go-around/missed-approach fail-safe remains the only narrow authoritative v4.7 terminal override.

### Data source

OurAirports data is public-domain/open data. The production build is pinned to source commit `e856aa3449d7f509af0b2f853b5c814ab28d0eb5` so a deployment is reproducible rather than silently consuming a newer nightly dump.

### Known limitations

The source is community-maintained and is not treated as official operational truth. Some facilities or runways may have missing/stale geometry; Plane Alerts degrades runway-specific inference to uncertain instead of inventing coordinates. Maintained overrides can replace individual airport records when stronger official information is available.
