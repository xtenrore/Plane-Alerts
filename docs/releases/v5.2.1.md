# Plane Alerts v5.2.1

Plane Alerts v5.2.1 is a documentation-truth and release-identity patch for the production-verified v5.2 evaluator.

## What changed

- Corrected the v5.2 canonical release documentation so ETA evaluation matches the final implementation.
- ETA truth is based only on an explicitly matched physical closest-observation timestamp.
- When that timestamp is unavailable, CPA/classification may still be evaluated from verified observed-pass distance, but ETA remains unavailable; lifecycle-resolution time is not substituted.
- Bumped the application release identity to `5.2.1` and updated release documentation.

## What did not change

- Physical prediction version remains `5.1-3d-proximity`.
- No trajectory, CPA, ETA predictor, confidence, altitude relevance, route/terminal suppression, qualification, cancellation, alert timing, provider, storage, Telegram, or shadow-candidate behavior changed.
- Runtime AI and AGY remain non-authoritative.
- No paid runtime dependency was added.

## Regression coverage

The v5.2 shadow suite continues to require:

- unresolved cancellations and missing ADS-B coverage remain unscored;
- physical closest-observation timestamps are preferred for ETA truth;
- absent physical closest timestamps do not become inferred lifecycle ETA truth;
- automatic shadow-model promotion remains disabled.

All inherited Error Museum, provider, Telegram, LTFM/LTBA/ISL terminal-arrival, storage, observability, v5.1 geometry, wrapper-chain, amd64 and ARM64 gates remain mandatory.
