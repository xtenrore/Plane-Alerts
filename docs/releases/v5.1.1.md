# Plane Alerts v5.1.1

Plane Alerts v5.1.1 is a narrow release-infrastructure patch for v5.1.0. It does not change trajectory, CPA, ETA, qualification, cancellation, terminal-arrival logic, or the v5.1 physical predictor.

## Fixed

- The trusted post-CI Railway deployment gate no longer executes its current-main verification inside `ghcr.io/railwayapp/cli:latest`.
- The v5.1.0 deployment failed because that container does not include `git`; `actions/checkout` therefore used archive mode and the subsequent `git fetch` command could not run.
- Current-main verification now runs in a separate standard GitHub-hosted `gate` job using the authenticated GitHub CLI/API.
- The Railway CLI container runs only when that gate confirms the exact tested SHA is still the current `main` head.
- Same-repository, successful-main-push trust checks remain mandatory, and stale tested commits are still refused.

## Prediction identity

Application version: `5.1.1`.

Physical prediction version remains `5.1-3d-proximity`.

No runtime AI or AGY authority is added, and no paid runtime service is introduced.

## Validation

The patch must pass the complete inherited regression, replay, performance, self-hosting and ARM64 gates. Production deployment must then confirm the exact tested v5.1.1 commit on both the main and AGY Railway services before v5.2 begins.

## Rollback

Application rollback target: Plane Alerts v5.1.0 commit `cdfcce190773e6e087e48cac373d7a8cfa1b6edb`.

If only deployment automation is at issue, the v5.1.0 application code itself remains the immediately preceding verified build candidate; production should never be advanced by bypassing the exact-SHA CI gate.
