# Plane Alerts v5.0.0

Plane Alerts v5.0 makes the existing deterministic prediction system explainable to operators without changing physical prediction behavior.

## Included

- `planealerts diagnostics` for recent per-aircraft why/why-not explanations from bounded Prediction Lab evidence
- `planealerts metrics` for provider health, worker cadence, database/storage latency, queue/drop state and notification telemetry
- provider diagnostics persisted through the existing monitor heartbeat: request/error/timeout counts, latency percentiles, last success, stale-position rate, circuit state and fallback readiness
- per-aircraft diagnostics covering trajectory state, current distance versus projected CPA, ETA, confidence, active/candidate ADS-B sources, route/terminal evidence and runway candidate data where available
- pseudonymized user references; credentials, provider endpoints and exact observer coordinates are excluded
- a dedicated v5.0 diagnostics overhead benchmark and CI gate
- AGY Mongo bridge resilience: short bounded reads, query max-time, circuit/backoff after Atlas failures, last-known-good redacted context fallback and concise degraded logging instead of repeated traceback storms

## Architecture and authority

v5.0 reuses existing telemetry instead of inserting a second prediction or provider implementation. The provider/runtime snapshot is attached to the monitor's existing system-status write, so no additional ADS-B request and no additional synchronous MongoDB write are added to the five-second alert path.

Runtime AI and AGY remain analysis-only. They do not control trajectory, CPA, ETA, confidence, runway/terminal inference, pass/no-pass, qualification, cancellation or alert timing.

Prediction version remains `4.7.3-terminal-delivery-landing-path`.

## Timeout behavior

AGY's Mongo bridge is non-critical. A Mongo network timeout opens a bounded cooldown circuit. While the circuit is open, the bridge immediately serves the last-known-good redacted context from `/agy-state` and continues independent `CHATGPT_HANDOFF_JSON` log delivery. Mongo is probed again after cooldown. Missing or stale cached evidence is labeled as such and must not be treated as a successful prediction outcome.

## Operator examples

```bash
planealerts metrics
planealerts diagnostics --aircraft 4bab24 --limit 5
planealerts diagnostics --callsign THY5DQ --limit 10
```

Prediction Lab snapshots are intentionally rate-limited; the diagnostics command labels sampled prediction counts accordingly rather than claiming they equal every five-second calculation.
