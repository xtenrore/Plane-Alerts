# Plane Alerts v4.2.1

v4.2.1 is a reliability release for the Prediction Lab and retired external agent audit path.

## Changes

- Bound point-heavy Prediction Lab Mongo cursors to small batches without changing query filters, forecast scoring, or alert logic.
- Keep the existing v4.3 Next60 quality gate and Europe sentinel evaluator as the calculation authority.
- Preserve normal shadow-audit retry cadence after transient database failures.
- Keep retired external agent analysis compatible with the minimal runtime image and supported headless tools.
- Refresh the project README for the v4.2.1 production release.

## Safety boundary

This release does not change deterministic production trajectory, CPA, ETA, pass/no-pass, qualification, cancellation, or notification timing logic. Missing ADS-B coverage remains unresolved rather than being scored as success or failure.
