# Plane Alerts v4.7.0 — Airport, Runway & Terminal Intelligence

## Scope

v4.7 builds on the existing v4.2 terminal guard and v4.6 confidence/turn infrastructure. It does not introduce a second live predictor.

## Changes

- Added a maintainable airport/runway geometry layer with LTFM/IST as the primary production Error Museum airport.
- Added bounded 12-minute terminal motion history, separate from the short production trajectory history used for live CPA.
- Added sustained-vector, downwind/base, final-intercept and established-final classification using multi-sample motion evidence.
- Added probable holding detection using elapsed time, accumulated turn geometry, geographic repeat and altitude band.
- Added go-around and missed-approach detection using prior final alignment followed by climb and heading deviation.
- Added recent observed runway-direction inference with recency weighting, unique-aircraft evidence, sample counts and explicit confidence. One aircraft cannot establish a runway configuration.
- Added bounded, time-decayed recent airport movement clusters for arrival, departure, vectoring, probable-hold and overhead/transit behavior.
- Added runway-family association for historical route paths as supporting evidence.
- Added structured v4.7 terminal/runway diagnostics to Prediction Lab for replay and AGY auditing.
- Added one live fail-safe: strong observed go-around/missed-approach evidence may release an existing expected-landing-turn hold so fresh live geometry can be re-evaluated. It cannot bypass the confirmed cancellation latch.

## Shadow policy

New runway/base/final/holding suppression hypotheses remain shadow-only in v4.7.0. They are measured against production behavior before any future promotion.

Fresh physical radius entry remains authoritative. Destination metadata, inferred runway direction, route history and airport proximity are not hard vetoes.

## Performance and resilience

- Provider snapshots are coalesced into at most one pending terminal-analysis task.
- Terminal history, runway evidence, movement clusters and diagnostics are all bounded and TTL-pruned.
- No database, weather or network lookup is added to the terminal classifier.
- Weather remains optional context and is not a runway selector.
- Google Contrails remains separate photography/environment enrichment and does not enter prediction or qualification.

## Validation

Release gates include the full existing suite plus v4.7 regressions for terminal entry, sustained/noisy turns, final intercept, holding, go-around/missed approach, runway inference, runway changes, parallel/crossing/single-runway layouts, IST arrival/go-around/overhead cases, stale ADS-B behavior and a dedicated terminal-intelligence benchmark.

## Known limitations

- v4.7.0 does not claim an official live runway assignment.
- Runway-specific inference is only available where maintained runway geometry exists; other airports still receive generic terminal context.
- Airport suppression candidates remain shadow-only until enough replay and production outcomes demonstrate improvement without missed genuine passes.
- Missing ADS-B coverage remains unresolved evidence, never a successful prediction or miss.
