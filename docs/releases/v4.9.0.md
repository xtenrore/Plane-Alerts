# Plane Alerts v4.9.0

Plane Alerts v4.9 makes the production project reproducible and supportable outside Railway without changing physical prediction behavior.

## Included

- exact Python runtime dependency lock
- MIT license and public issue-reporting path
- Docker Compose deployment with MongoDB persistence, service health checks and restart policies
- explicit amd64 and ARM64 Docker support; Raspberry Pi uses the same ARM64 image path
- `planealerts doctor` for secret-safe configuration, MongoDB, Telegram, ADS-B provider, local receiver, stored-coordinate-range and compatibility checks
- installation, upgrade, migration and rollback documentation
- CI gates for self-hosting artifacts, doctor behavior, fresh Docker installation and both supported CPU architectures

The existing v4.8 MongoDB isolation, restart safety, bounded persistence and five-second monitor design remain unchanged. Runtime AI continues to have no authority over trajectory, CPA, ETA, confidence, runway use, qualification, cancellation or alert timing.

Prediction version remains `4.7.3-terminal-delivery-landing-path`.
