# Plane Alerts v5.3.0

Plane Alerts v5.3.0 is the Multi-Location & Scale release. It reduces duplicated work when many observers share the same regional aircraft data while preserving each observer's independent deterministic safety decision.

## What changed

- Added a bounded shared aircraft-motion layer for observer-independent latitude/longitude/altitude/heading projection.
- Added separate bounded reuse for the authoritative v4.3 midpoint-integrated path.
- Installed shared motion beneath the established production predictor chain, preserving the order `shared base -> v4.3 midpoint -> v4.4 direct presence -> v4.6 confidence -> critical timing`.
- Added a spatial user/aircraft candidate index before per-user evaluation. The index is acceleration-only; exact Haversine distance against the established `radius + 120 km` monitoring envelope remains authoritative.
- Added explicit per-user candidate bounds and bounded 1,024-entry LRU motion caches.
- Reused existing shared regional ADS-B snapshots and existing enrichment caches. v5.3 does not introduce an additional provider-polling layer.
- Added scale diagnostics for candidate/full pair counts, pair reduction, per-user candidate maxima, cap hits and motion-cache reuse.

## What did not change

- Physical prediction version remains `5.1-3d-proximity`.
- Observer-specific horizontal CPA, 3D relevance, ETA, confidence, route/terminal evidence, qualification, cancellation and alert timing remain independent per user.
- v4.7.3 terminal-arrival delivery protection remains authoritative.
- Missing ADS-B coverage remains unresolved and is never treated as a successful prediction or miss.
- Runtime AI and AGY remain non-authoritative for physical prediction and alert timing.
- No paid runtime dependency was added.

## Release gates

v5.3 adds deterministic coverage for:

- shared-motion output equivalence to the established predictor;
- complete wrapper-chain preservation;
- multiple observers sharing motion without sharing observer state;
- spatial-index equality with brute-force candidate truth;
- explicit memory/cache bounds;
- explicit per-user work bounds;
- inherited provider-call sharing and five-second polling behavior;
- 500-user / 600-aircraft scale benchmarking;
- all inherited Error Museum, LTFM/LTBA/ISL terminal-arrival, provider, Telegram, storage, observability, 3D-geometry and shadow-evaluation gates;
- fresh amd64 and ARM64 container validation.

## Operational notes

The spatial index never decides whether an aircraft qualifies for an alert. It only avoids sending geographically impossible pairs into the expensive observer-specific predictor. Every indexed candidate still receives the same exact distance and full deterministic prediction/terminal/lifecycle evaluation as before.

Both motion caches are process-local, bounded and derived only from accepted aircraft observations. They contain no user coordinates or user lifecycle state.
