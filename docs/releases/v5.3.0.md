# Plane Alerts v5.3.0

Plane Alerts v5.3.0 is the Multi-Location & Scale release. It reduces duplicated work when many observers share the same regional aircraft data while preserving each observer's independent deterministic safety decision. It also includes two narrowly verified Prediction Lab/AGY fixes in the physical prediction chain.

## What changed

- Added a bounded shared aircraft-motion layer for observer-independent latitude/longitude/altitude/heading projection.
- Added separate bounded reuse for the authoritative v4.3 midpoint-integrated path.
- Installed shared motion beneath the established production predictor chain, preserving the order `shared base -> v4.3 midpoint -> v4.4 direct presence -> v4.6 confidence -> critical timing`.
- Added a spatial user/aircraft candidate index before per-user evaluation. The grid is acceleration-only; exact spherical great-circle membership against the established `radius + 120 km` monitoring envelope remains authoritative. The hot path evaluates the same spherical boundary using precomputed unit vectors and a dot-product threshold, which is mathematically equivalent to the previous Haversine threshold while avoiding repeated inverse-trigonometric work.
- Added explicit per-user candidate bounds and bounded 1,024-entry LRU motion caches.
- Reused existing shared regional ADS-B snapshots and existing enrichment caches. v5.3 does not introduce an additional provider-polling layer.
- Added scale diagnostics for candidate/full pair counts, pair reduction, per-user candidate maxima, cap hits and motion-cache reuse.
- Fixed the v4.3 midpoint ETA path so provider-reported ADS-B position age is treated as real observation latency. This removes a reproducible late-ETA bias identified from AGY seq140 evidence and brings the midpoint wrapper into line with the authoritative base freshness semantics.
- Tightened the cancellation latch so a stale observation inside the configured radius cannot revive a cancelled encounter. Fresh direct physical presence can still recover it.

## Prediction identity and safety

The physical prediction version is `5.3-3d-proximity-age-aware` because provider-reported observation age now changes physical ETA/entry timing in the authoritative wrapper chain.

Observer-specific horizontal CPA, 3D relevance, confidence, route/terminal evidence, qualification, cancellation and alert timing remain independent per user. No terminal-arrival threshold, qualification threshold or alert-delivery timing policy changed. The v4.7.3 LTFM/LTBA/ISL terminal-arrival protections remain authoritative.

Missing ADS-B coverage remains unresolved and is never treated as a successful prediction or miss. Runtime AI and AGY remain non-authoritative for physical prediction and alert timing. No paid runtime dependency was added.

## Release gates

v5.3 adds deterministic coverage for:

- shared-motion output equivalence to the established predictor;
- complete fresh-interpreter production wrapper-chain preservation;
- multiple observers sharing motion without sharing observer state;
- spatial-index equality with brute-force spherical/Haversine candidate truth;
- explicit memory/cache bounds;
- explicit per-user work bounds;
- inherited provider-call sharing and five-second polling behavior;
- provider-position-age ETA correction and stale cancellation-latch safety;
- 500-user / 600-aircraft scale benchmarking;
- all inherited Error Museum, LTFM/LTBA/ISL terminal-arrival, provider, Telegram, storage, observability, 3D-geometry and shadow-evaluation gates;
- fresh amd64 and ARM64 container validation.

## Operational notes

The spatial index never decides whether an aircraft qualifies for an alert. It only avoids sending geographically impossible pairs into the expensive observer-specific predictor. Every indexed candidate still receives the same full deterministic prediction/terminal/lifecycle evaluation as before.

Both motion caches are process-local, bounded and derived only from accepted aircraft observations. They contain no user coordinates or user lifecycle state.
