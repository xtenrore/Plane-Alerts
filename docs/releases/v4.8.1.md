# Plane Alerts v4.8.1

Plane Alerts v4.8.1 is a focused storage-resilience patch discovered during v4.8.0 production verification.

## Fixed

- Stop evaluating Motor/PyMongo database handles as booleans in the v4.8 storage runtime. Motor intentionally raises `NotImplementedError` for database truth-value testing, which could incorrectly route a healthy Mongo connection through the degraded-startup reconnect path.
- Preserve the v4.8 memory-first monitoring and bounded persistence behavior; physical prediction logic is unchanged.

## Verification

The patch adds an exact regression using a Motor-like database object whose `__bool__` raises `NotImplementedError`. Warm-up, configuration refresh and bounded flush paths must all accept that object without truth testing. All inherited v4.4-v4.8 regressions and performance gates remain required before release.

Prediction version remains `4.7.3-terminal-delivery-landing-path`.
