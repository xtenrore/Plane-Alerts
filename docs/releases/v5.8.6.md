# Plane Alerts v5.8.6 — Bounded ADS-B Diagnostics

## Change

Production logged repeated `adsb_outlier_rejected` warnings for zero-distance repeated observations, including dozens in a 30-second sample. These observations were already rejected correctly, but repeated warnings obscured distinct events and added avoidable log traffic.

The `app.worker.v35` logger now emits at most one zero-jump outlier warning every 60 seconds and includes the count of suppressed repeats on the next emission. Nonzero-jump warnings continue immediately. The filter affects diagnostic logging only: it does not change observation rejection, provider selection, trajectory, CPA, ETA, qualification, cancellation or alert timing. Prediction version stays `5.3-3d-proximity-age-aware`.

## Validation and release scope

Regression tests exercise repeated zero-jump warnings, nonzero-jump warnings and idempotent installation on the actual production logger. The Railway release requires the full application CI, Error Museum/replay and benchmark steps, exact tested main commit, production readiness, maintenance, five-second monitoring cadence, and a sample of live warnings after deploy.

No configuration, dependency, database schema, installer, updater or rollback compatibility change. COMMUNITY IMPACT: the shared worker logger also runs in self-host installations; the weekly Community Release workflow owns full platform validation.
