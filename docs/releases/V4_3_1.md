# Plane Alerts v4.3.1

Plane Alerts v4.3.1 improves the reliability of the private retired external agent Prediction Lab worker without widening its command permissions.

## Changes

- Soft-denied headless commands now resume the exact retired external agent conversation immediately using its conversation ID.
- The previous multi-minute permission backoff is removed from the normal tooling-mistake path.
- Recovery guidance escalates after repeated unsupported command choices and eventually forces built-in inspection tools plus Python standard-library scripts.
- Recovery is bounded to four corrective turns, then falls back to a short retry instead of an unbounded loop.
- Conversation IDs can be recovered from truncated stream-json log lines.
- retired external agent health output exposes recovery mode and current recovery count.
- Persisted tooling guidance explicitly rejects `cat`, `find`, `sed`, `head`, `tail`, pipes, redirects, heredocs and shell command chains.

## Safety invariants

- No `command(*)` permission.
- No `--dangerously-skip-permissions`.
- No broader shell or `bash` access.
- Paid AI-credit overages remain disabled.
- Prediction Lab remains advisory only; live trajectory, CPA, ETA and alert timing stay deterministic.
