# Plane Alerts v5.8.0 — Flightradar24 Aircraft Links

Plane Alerts v5.8.0 standardizes user-facing aircraft tracking links on Flightradar24.

## User-visible changes

- Live alert action buttons now open Flightradar24 instead of ADSB.fi.
- Legacy aircraft alert text now links to Flightradar24.
- Next 60 Minutes aircraft buttons now use Flightradar24 instead of adsb.lol.
- When a usable callsign is available, Plane Alerts opens the matching Flightradar24 callsign URL directly.
- ICAO24-only observations fall back to Flightradar24's Data page instead of fabricating an aircraft URL from a hex address.

## Implementation and safety

- Flightradar24 is used only as an external user-facing link target. Plane Alerts does not add a Flightradar24 API dependency or make Flightradar24 part of the live ADS-B provider chain.
- Existing ADS-B ingestion providers and fallback behavior are unchanged.
- No paid AI/API dependency is introduced.
- No database schema, environment-variable, installer, updater or service-command change is required for this Railway release.

## Prediction contract

No trajectory, CPA, ETA, confidence, destination/path qualification, pass/no-pass, cancellation or alert-timing logic changes are introduced by v5.8.0.

Physical prediction version: `5.3-3d-proximity-age-aware`.

## Release lineage

v5.8.0 follows the v5.7.1 cumulative Bug Fixes Update and preserves all v5.7.1 reliability/storage work. Community/self-host stable publication remains owned by the separate weekly community validation workflow.
