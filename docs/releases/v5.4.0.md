# Plane Alerts v5.4.0 — User Experience & Presets

Plane Alerts v5.4 is a user-experience release. The authoritative physical prediction model remains `5.3-3d-proximity-age-aware`; this release does not change trajectory, CPA, ETA, confidence, route/terminal inference, qualification, cancellation, or alert timing.

## Guided profiles and presets

`/profiles` now opens a clearer alert-profile home with direct access to profile status and an explicit Close action. Creating a profile offers two understandable paths:

- **Quick Preset** — start from one of six editable configurations.
- **Custom Setup** — use the complete existing profile wizard.

The six presets are:

1. Casual Observer
2. Aircraft Photographer
3. Airport-Adjacent
4. Rare Aircraft Hunter
5. Military Watcher
6. Local SDR Mode

Presets only populate existing profile fields such as radius, aircraft groups, and advanced-filter defaults. They preserve the user's saved coordinates and unrelated preferences. Applying a preset to an existing profile requires an explicit preview/confirmation, resets hidden aircraft/category overrides so the visible preset means what it says, and leaves every setting editable afterward.

Local SDR Mode changes alert preferences only. It does not claim to configure or enable a receiver; local ADS-B connectivity remains an operator/deployment setting.

## Navigation, validation, and recovery

- `/preferences` now opens the active profile editor instead of dropping users directly into the aircraft picker.
- Profile home/detail, preset setup, location/radius editing, confirmation, and status views have explicit Back, Cancel, Close, or Save actions as appropriate.
- Re-running `/profiles` or `/preferences` clears an interrupted profile interaction and safely restarts from a known screen.
- Preset validation failures lead users directly to the missing location, radius, or aircraft setting instead of leaving them in a dead end.
- Telegram button text is deliberately short and callback payloads stay within Telegram's 64-byte limit.
- Stale profile/preset callbacks recover to the profile home instead of leaving the conversation trapped.

## Diagnostics accessibility

Profile home includes a user-safe Status view with active profile, location-saved state, radius/filter summary, and running Plane Alerts version. Exact stored coordinates are intentionally not displayed in this compact view. Existing `/status`, `/help`, and operator `planealerts diagnostics` / `planealerts metrics` remain available.

## Mini App consistency

The existing Next 60 Mini App continues to be the only Mini App surface; v5.4 does not invent a separate settings web app. Its visible branding now consistently says **Plane Alerts** rather than the retired `Plane?` name. Forecast truth semantics are unchanged: live CPA remains authoritative and 30–60-minute historical expectations remain shadow-only.

## Safety and compatibility

- Physical prediction version remains `5.3-3d-proximity-age-aware`.
- v4.7.3 LTFM/LTBA/ISL terminal-arrival protections remain release gates.
- v5.3 shared-motion/spatial scale behavior remains active and independently tested.
- Preset/profile work is outside the five-second monitoring path and performs no ADS-B provider request.
- Existing profile storage/materialization remains authoritative; v5.4 is a higher-priority presentation layer around the proven profile engine.
- Routine production deployment targets the main Plane Alerts Railway service only. The AGY service and its persistent volume are not restarted by a normal source release.
- The unrelated staged Railway configuration patch remains outside this release.

## Release gates

v5.4 adds dedicated regressions for all six presets, supported category mappings, coordinate/unrelated-setting preservation, editability, setup recovery, navigation controls, actionable validation, callback-size safety, `/preferences` behavior, Mini App branding, and the absence of prediction/network dependencies in preset logic.

A deterministic preset/profile micro-benchmark is also required in addition to every inherited Error Museum, provider, Telegram, terminal-arrival, storage, observability, 3D geometry, shadow-evaluation, v5.3 scale, amd64, and ARM64 gate.

## Rollback

The production rollback point before this release is Plane Alerts v5.3.0 at `0f25af8b04aeef349db5b4e386b0c4b42b45afc8`. If v5.4 production verification discovers a regression, roll the main Plane Alerts service back to that exact tested commit and leave the AGY persistent volume and unrelated staged Railway configuration unchanged.
